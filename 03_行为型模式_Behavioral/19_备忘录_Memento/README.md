# 备忘录模式 (Memento Pattern)

## 定义

在不破坏封装性的前提下，保存和恢复对象内部状态。

## 原理

保存对象状态到备忘录（Memento），由管理员（Caretaker）管理备忘录， originator（发起人）可以创建备忘录保存状态，也可以从备忘录恢复状态。

## 角色

- **Originator（发起人）**：需要保存和恢复状态的对象
- **Memento（备忘录）**：存储发起人内部状态的对象
- **Caretaker（管理员）**：负责保管备忘录，不能直接访问备忘录内容

## 优点

- 保存对象状态，便于撤销操作
- 简化发起人Originator，状态保存由备忘录管理

## 缺点

- 如果状态频繁保存，可能占用大量内存
- 管理员需要管理多个备忘录对象

## 适用场景

- 需要撤销功能的场景（如编辑器、游戏）
- 需要保存历史快照的场景（如事务回滚、版本管理）
- 对象状态的保存与恢复
