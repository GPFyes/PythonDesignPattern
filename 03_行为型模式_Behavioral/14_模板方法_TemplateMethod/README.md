# 模板方法模式 (Template Method Pattern)

## 定义
定义算法骨架，将某些步骤延迟到子类中实现。模板方法模式使得子类可以在不改变算法结构的情况下，重新定义算法中的某些步骤。

## 原理
父类定义算法框架（模板方法），将具体步骤委托给子类实现，子类通过覆盖这些步骤来改变算法的行为。

## 角色
- **AbstractClass**: 抽象类，定义模板方法和抽象方法
- **ConcreteClass**: 具体类，实现抽象方法完成算法中特定步骤

## 优点
1. 代码复用
2. 符合开闭原则
3. 封装不变部分，扩展可变部分
4. 行为由父类控制，子类负责实现

## 缺点
1. 可能增加代码复杂度
2. 子类可能影响父类行为
3. 难以维护较长的算法

## 适用场景
1. 算法的骨架固定，但某些步骤可变
2. 多个类有共同行为，但实现细节不同
3. 需要控制子类的扩展点
