# 适配器模式 (Adapter)

## 定义

将一个类的接口转换成客户期望的另一个接口，使原本不兼容的类可以合作。

## 原理

适配器模式通过将一个类的接口转换为另一个接口，使不兼容的类能够一起工作。

## 角色

| 角色 | 职责 |
|------|------|
| Target | 目标接口 |
| Adaptee | 被适配者 |
| Adapter | 适配器 |

## 优点

1. **复用现有类**：无需修改原有代码
2. **解耦**：客户端与实现解耦

## 缺点

1. **增加复杂度**：引入额外层次
