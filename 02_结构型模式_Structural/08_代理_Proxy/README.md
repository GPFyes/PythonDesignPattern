# 代理模式（Proxy Pattern）

## 定义
为另一个对象提供一种代理，以控制对这个对象的访问。

## 原理
通过代理对象间接访问真实对象，代理对象可以在访问真实对象前后执行额外的操作。

## 角色
- **Subject（抽象主题）**：定义真实主题和代理的公共接口
- **RealSubject（真实主题）**：真正执行业务逻辑的对象
- **Proxy（代理）**：持有真实主题的引用，提供与真实主题相同的接口

## 优点
- 控制访问：可以在代理中限制、修改或增强对真实对象的访问
- 保护真实对象：隐藏真实对象的复杂性
- 职责分离：解耦客户端和真实对象

## 缺点
- 增加复杂度：需要创建代理类，增加了系统复杂度
- 性能开销：代理层可能导致性能略微下降

## 适用场景
- **远程代理**：为远程对象提供本地代理
- **虚代理**：延迟加载大型对象
- **保护代理**：控制对敏感对象的访问
- **智能引用**：在访问对象时执行额外操作
